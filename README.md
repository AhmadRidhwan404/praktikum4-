# praktikum4-
**Program Input Data dan Nilai Mahasiswa**

Program ini merupakan contoh sederhana untuk menambahkan data mahasiswa ke dalam list dan menghitung nilai akhir berdasarkan tiga komponen nilai:

Tugas (30%)

UTS (35%)

UAS (35%)

 Deskripsi Program

Program ini meminta pengguna untuk:

Menginputkan nama mahasiswa dan NIM.

Memasukkan nilai tugas, UTS, dan UAS.

Program akan otomatis menghitung nilai akhir menggunakan rumus:
Nilai Akhir = (Tugas * 0.30) + (UTS * 0.35) + (UAS * 0.35)

Data setiap mahasiswa akan disimpan dalam list berisi beberapa dictionary.

Pengguna bisa menambah data mahasiswa sebanyak yang diinginkan.

Ketika pengguna menjawab t (tidak), program menampilkan daftar seluruh mahasiswa beserta nilainya.

##**contoh output**##
=== Input Data Mahasiswa ===
Nama mahasiswa: Ahmad
Masukkan NIM: 23123456
Nilai Tugas (30%): 80
Nilai UTS (35%): 85
Nilai UAS (35%): 90

Tambah data lagi? (y/t): t

=== Daftar Nilai Mahasiswa ===
No  Nama        NIM       Tugas  UTS  UAS  Nilai Akhir
------------------------------------------------------------
1. Ahmad        23123456  80.0   85.0 90.0 85.75
